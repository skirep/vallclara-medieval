# Prone residents, version 1

Runtime asset: `assets/packed/resident-corpses-v1.webp` (1024 × 256, four columns, two rows, lossless alpha). Eight shared visual variants: villager, woman, elder, child, royal guard, ninja, king, queen. This atlas supplies new drawn prone bodies; it does not rotate the standing sprites. Individual outfits are represented by these eight archetypes rather than 100 unique corpse designs.

Generated using the built-in image generation tool. Original: `exec-066d1301-b90e-4f9f-9414-7c6e84da73f8.png`; transparency refinement: `exec-9f37d795-f9a8-4d7b-8c25-d68cca94cb69.png`. The original has a 4 × 2 layout on a 1536 × 1024 canvas. `scripts/pack-corpses.cjs` measures each alpha silhouette, applies the same 115 alpha threshold used by the other resident packers, and packs it into a centered 256 × 128 cell using nearest-neighbor resampling. Reproduce with `node scripts/pack-corpses.cjs SOURCE.png`.
